# 차즘 NAS · ChaZeum NAS

Windows PC의 폴더나 데이터 드라이브를 골라 여러 사람에게 따로 공유하는 두 개의 작은 앱입니다. 관리자와 접속자가 각자 위치와 드라이브 문자를 정합니다. 서버에 둔 파일은 사용자 PC에 남아 있으며, 프로그램 배포처에 업로드되지 않습니다.

| 파일 | 누가 무엇을 하나요? |
| --- | --- |
| 서버용.exe | 집 PC의 관리자가 여러 폴더 또는 로컬 NTFS 데이터 드라이브를 추가합니다. 직접 만든 NAS 아이디마다 각 공유의 권한을 ‘접근 안 됨’, ‘읽기’, ‘읽기·쓰기·삭제’ 중에서 선택합니다. Windows 시스템 드라이브 전체는 제외합니다. |
| 유저용.exe | 접속하는 사람이 서버 주소와 NAS 계정을 설정한 뒤, 각 공유에 원하는 빈 드라이브 문자를 부여해 Windows 탐색기에서 사용합니다. |

아이폰·아이패드는 기본 **파일 → 둘러보기 → … → 서버에 연결**에서 SMB로 접속합니다. 집 밖에서는 먼저 집으로 연결되는 VPN이 필요합니다. 이 버전의 Windows 앱은 집에 설정된 L2TP/IPsec VPN과 Windows 기본 VPN 기능을 사용합니다. 공인 IP 또는 DDNS 이름을 직접 입력할 수 있습니다. 앱은 IP 주소나 도메인을 발급하지 않으며, 공유기나 인터넷에 파일 공유 포트를 자동으로 열지 않습니다.

**상태 (5.0.0.3):** 이 자료는 미서명 개발 버전의 소스입니다. 여기에는 설치 파일이 없습니다. 두 Windows 프로그램의 빌드 결과를 바이트 단위로 대조했지만, SignPath 승인·서명, 대상 Windows에서의 실행, 실제 집 밖 기기의 파일 저장·속도는 아직 확인되지 않았습니다. 차단된 프로그램 때문에 Windows 보안을 끄지 마세요.

### 빌드와 확인

Debian 13 x86-64에서 GCC 14, GNU binutils 2.44, libLLVM 19, Python 3 및 python3-pypdf를 사용합니다. 저장소 루트에서 다음 순서로 실행합니다. 테스트는 운영체제 동작 일부를 대역으로 검사하고, 임시 디스크에 실제로 쓴 데이터도 비교합니다. 외부 NAS 속도나 실제 Windows 실행을 증명하지는 않습니다.

```sh
python3 -B tools/build.py
python3 -B tests/check.py
python3 -B release/verify_payload.py out
```

Windows x64용 두 파일은 out/에 생성됩니다. 안내서 원본은 docs/guide.py와 docs/menus.py이고, 앱에는 체크인된 PDF를 그대로 포함합니다.

### 사용 중단

접속 PC에서는 **확인·자동 연결 → 자동 연결 끄기**, **드라이브**에서 등록한 연결 해제, **외부 VPN**에서 이 앱으로 만든 프로필 해제를 사용합니다. 서버에서는 **공유할 위치**에서 해당 공유를 해제하고, **연결 확인 → 이 앱 규칙 제거**로 추가했던 방화벽 규칙을 정리할 수 있습니다. NAS 전용 로컬 계정은 필요 여부를 확인한 뒤 Windows에서 별도로 정리합니다. 이후 두 EXE를 삭제할 수 있습니다. 공유한 원본 폴더를 지울 필요는 없습니다. 자동 연결을 사용한 적이 있다면 해제 후 개인 앱 폴더에 남은 실행 파일도 정리할 수 있습니다.
