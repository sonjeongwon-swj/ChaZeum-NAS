# 차즘 NAS · ChaZeum NAS

Windows PC의 폴더나 데이터 드라이브를 골라 여러 사람에게 따로 공유하는 두 개의 작은 앱입니다. 관리자와 접속자가 각자 위치와 드라이브 문자를 정합니다. 서버에 둔 파일은 사용자 PC에 남아 있으며, 프로그램 배포처에 업로드되지 않습니다.

| 파일 | 누가 무엇을 하나요? |
| --- | --- |
| Chazeum-NAS_SERVER.exe | 집 PC의 관리자가 여러 폴더 또는 로컬 NTFS 데이터 드라이브를 추가합니다. 직접 만든 NAS 아이디마다 각 공유의 권한을 ‘접근 안 됨’, ‘읽기’, ‘읽기·쓰기·삭제’ 중에서 선택합니다. Windows 시스템 드라이브 전체는 제외합니다. |
| Chazeum-NAS_USER.exe | 접속하는 사람이 서버 주소와 NAS 계정을 설정한 뒤, 각 공유에 원하는 빈 드라이브 문자를 부여해 Windows 탐색기에서 사용합니다. |

아이폰·아이패드는 기본 **파일 → 둘러보기 → … → 서버에 연결**에서 SMB로 접속합니다. 집 밖에서는 먼저 집으로 연결되는 VPN이 필요합니다. 유저용은 이미 연결된 WireGuard·Tailscale을 이용하거나, 이전 버전과 같이 공유기의 L2TP/IPsec VPN을 사용할 수 있습니다. 공인 IP 또는 DDNS 이름을 직접 입력할 수 있습니다. 앱은 IP 주소나 도메인을 발급하지 않으며, 공유기나 인터넷에 파일 공유 포트를 자동으로 열지 않습니다.

**5.0.1.0 유저용 시험판:** 노트북에 집으로 연결되는 WireGuard 터널 또는 집 PC와 같은 Tailscale 개인망이 이미 있어야 합니다. 새 VPN이나 방화벽 규칙을 설치하지 않습니다.

1. **1. 서버 주소**에서 NAS PC의 IPv4와 Windows 컴퓨터 이름을 입력한 뒤 **기존 보안망으로 등록**을 누릅니다. WireGuard는 집 PC의 내부 주소, Tailscale은 그 PC의 Tailscale IPv4를 사용합니다. 이 방식은 도메인 칸을 비워 둡니다.
2. **3. 드라이브**에서 NAS 아이디·암호를 입력하고 공유 이름과 사용할 드라이브 문자를 선택한 뒤 **드라이브 연결·저장**을 누릅니다. 원하면 **4. 확인·자동 연결 → 로그인 때 자동 연결**을 켭니다. 등록한 외부 터널이 연결되어 있을 때만 작동합니다. 기존 방식으로 연결한 다른 드라이브나 앱 전용 VPN이 남아 있다면 앱은 서버 등록을 바꾸지 않습니다. 보안 연결이 끊기거나 달라진 경우 앱은 새 연결을 중단합니다. 이미 열려 있는 탐색기 연결은 Windows가 관리합니다.
3. 집 밖에서 **4. 확인·자동 연결 → 256 MiB 시험**을 누르면 새 파일을 쓰고 다시 열어 일치 여부와 읽기·쓰기 MB/s를 확인합니다. Tailscale이 제공하는 직결·중계 상태를 표시하고, WireGuard는 경로 형태를 추정하지 않습니다. **아이폰·아이패드**에서는 기기 자체의 VPN을 연결한 뒤 기본 **파일 → 둘러보기 → … → 서버에 연결**에서 `smb://NAS의주소`를 입력하고 ‘등록 사용자’로 로그인하세요. Windows용 설정을 모바일에서 가져올 필요는 없습니다.

**5.0.0.4에서 추가한 서버 기능:** 첫 화면 **서버 상태**에 Windows 파일 공유의 실제 실행 여부, 부팅 때 자동 시작 여부와 이 앱으로 등록한 공유 수를 표시합니다. **부팅 때 공유 시작**은 확인을 받은 뒤 이 PC의 Windows 파일 공유 서비스를 자동으로 설정하고 시작합니다(기존 Windows 공유에도 적용). **수동 시작으로 변경**은 실행 중인 서비스를 끄지 않습니다. **트레이로 숨기기**는 관리 창만 숨깁니다. 아이콘을 누르면 다시 열립니다. **×**로 프로그램을 종료해도 등록한 공유는 유지됩니다. PC가 꺼지거나 절전 중이면 접속할 수 없습니다. 전체 드라이브를 추가할 때는 하위 파일의 Windows 권한 적용 등 현재 단계와 경과 시간을 보여 줍니다.

**교체:** 같은 PC·같은 Windows 사용자에서 창을 ×로 닫고, 사용하던 로컬 폴더에 같은 이름의 새 EXE를 덮어씁니다. 이름이 달랐던 5.0.0.3에서는 새 이름으로 한 번만 옮겨 시작합니다. 공유·권한은 Windows에, 주소·연결 설정은 기존 앱과 같은 위치에 있습니다. 기존 Windows 공유와 위치가 겹치면 충돌한 이름과 경로를 표시합니다. 공유 목록을 읽지 못한 경우에는 Windows 오류 코드를 따로 표시합니다. 로그인 자동 연결을 켰던 구버전에서만 유저용을 처음 실행할 때 새 파일을 사용하도록 한 번 동의를 묻습니다. 이후 같은 경로에 교체하면 됩니다. 현재 자동 다운로드 기능은 없습니다.

**계정:** 한글과 공백을 포함한 Windows 로컬 계정 이름을 사용할 수 있습니다. 앱은 암호에 별도 최소 길이나 조합을 요구하지 않습니다. 기존 계정을 덮어쓰지 않으며, Windows 자체 계정 정책은 변경하지 않습니다.

이 소스에서 빌드한 시험판은 미서명입니다. Windows 실행·교체 시험 결과는 해당 커밋의 Actions에서 확인할 수 있습니다. 가정 내 3080 PC와 외부 아이폰·아이패드·노트북의 원격 저장 및 실제 전송 속도는 별도 시험 항목입니다.

### 빌드와 확인

Debian 13 x86-64에서 GCC 14, GNU binutils 2.44, libLLVM 19, Python 3 및 python3-pypdf를 사용합니다. 저장소 루트에서 다음 순서로 실행합니다. 테스트는 운영체제 동작 일부를 대역으로 검사하고, 임시 디스크에 실제로 쓴 데이터도 비교합니다. 외부 NAS 속도나 실제 Windows 실행을 증명하지는 않습니다.

```sh
python3 -B tools/build.py
python3 -B tests/check.py
python3 -B release/verify_payload.py out
```

Windows x64용 두 파일은 out/에 생성됩니다. 안내서 원본은 docs/guide.py와 docs/menus.py이고, 앱에는 체크인된 PDF를 그대로 포함합니다.

### 사용 중단

접속 PC에서는 **확인·자동 연결 → 자동 연결 끄기**, **드라이브**에서 등록한 연결 해제, **외부 VPN**에서 이 앱으로 만든 프로필 해제를 사용합니다. 서버에서는 **공유할 위치**에서 해당 공유를 해제하고, **연결 확인 → 이 앱 규칙 제거**로 추가했던 방화벽 규칙을 정리할 수 있습니다. NAS 전용 로컬 계정은 필요 여부를 확인한 뒤 Windows에서 별도로 정리합니다. 이후 두 EXE를 삭제할 수 있습니다. 공유한 원본 폴더를 지울 필요는 없습니다. 자동 연결을 사용한 적이 있다면 해제 후 개인 앱 폴더에 남은 실행 파일도 정리할 수 있습니다.
